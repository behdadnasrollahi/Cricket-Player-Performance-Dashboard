# 🏏 Cricket Player Performance Dashboard

## 📌 Project Overview

This project focuses on analyzing cricket player performance using Microsoft Power BI and interactive data visualization.

The goal is to present player statistics in a clear and meaningful way to support performance analysis and comparison.

## 🎯 Project Objectives

- Analyze cricket player performance.
- Explore key player statistics.
- Compare player performance using relevant metrics.
- Present insights through data visualization.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Data Analysis
- Data Visualization

## 📊 Key Features

- Player performance analysis
- Statistical comparison
- Interactive data exploration, where supported by the report

The Power BI report and supporting project files will be added to this repository.
